# 网络视频资料库

当前优先完成网络视频的收集、整理、下载和回看。浏览器首页与 `#videos` 都进入资料库；本阶段不运行转写、AI 总结或知识库索引。

## 打开与使用

安装项目的 Python 和网页依赖后，双击根目录的 `启动项目.bat`，打开 <http://127.0.0.1:5173/#videos>。这是运行在自己电脑上的网页工具，尚未打包成免安装软件。仅使用资料库不需要模型密钥，也不需要登录抖音。

下载功能需要可用的 ffmpeg。后端依赖中固定了 `yt-dlp==2026.10.21`、`yt-dlp-ejs==0.8.0` 和 `deno==2.9.8`；更新项目后在 `backend` 运行 `uv sync`，再启动服务。若 ffmpeg 未在系统 Path 中，需要先配置其安装目录。当前开发环境也兼容仓库上级 `.phase0-tools/bin/` 中已准备的 ffmpeg。

1. 把平台的完整分享文字或视频链接粘贴到“收集视频链接”，一次最多 20 个。可混合抖音、Bilibili、YouTube 和公开视频文件直链。
2. 点击“保存链接”。这一步不访问原站、不下载视频。重复的规范化链接会复用已有记录，保留标题、标签与备注。
3. 在详情中编辑标题、标签和备注，点击“保存修改”；可使用星标、搜索和平台筛选。归档仅将记录收起，可以恢复。
4. 需要本地副本时单独点击下载。查看排队、下载、成功或失败状态；可取消，失败后可手动重试。
5. 成功后可在详情播放本地视频，或点击“下载原件”保存副本。打开原站的入口始终保留。

网络来源尚未与本地字幕工作台互通；下载成功不自动生成逐字稿。需要原工具时，可从侧栏进入 `#local` 或原抖音知识库 `#douyin`。

## 能力与限制

| 项目 | 当前行为 |
| --- | --- |
| 抖音、Bilibili、YouTube | 可保存单视频来源并尝试匿名下载；各平台和具体视频的结果以实际尝试为准。 |
| 公开直链 | 支持 MP4、WebM、MOV、M4V 文件链接；成功后仍需通过媒体完整性检查。 |
| 其他网站 | 可保存安全的公开来源链接，当前不提供通用下载适配。 |
| 下载范围 | 单视频，最多 500 MiB、2 小时；单次任务最长 15 分钟；平台格式选择最高 720p。直链不会降分辨率转码。 |
| 暂不支持 | 直播、合集批量下载、HLS、需要账号或付费权限的下载，以及当前格式选择无法处理的视频。 |
| 去重 | 按规范化 URL 去重，YouTube 分享链接与标准链接可合并；尚未把所有短链与解析后的长链合并为同一视频。 |
| 进度 | 能取得总大小时显示字节进度；提取地址、合并或校验时不伪造百分比。 |

“可保存来源”“已识别平台”和“已下载到本机”是不同状态。失败时标题、标签、备注和原始链接仍保留；重新下载失败也不会覆盖此前成功的视频。首批真实验收见 [网络视频报告](NETWORK_VIDEO_REPORT.md)。

本功能不会读取浏览器 Cookie、旧抖音登录配置、代理或模型密钥。登录或验证需要在原站由用户完成；当前未实现把原站登录状态连接到资料库，因此在浏览器登录后点击重试，也不保证匿名下载能成功。

## 取消、重启与编辑冲突

点击取消会停止该次下载及其媒体处理子进程。后台重启后，未完成任务标记为“已中断”，不会自动重新发起网络请求；需要手动重试。已成功的本地副本保持可用。

多个页面同时编辑同一条资料时，较旧的保存会提示冲突并保留草稿；先对照最新内容合并，再保存。保存期间继续输入的新文字也会保留为未保存草稿。编辑备注、星标或标签不应导致正在播放的视频重新加载。

## 数据位置与备份

默认存储位于 `backend/app/storage/local_media_workspace/network/`：

- `sources/`：链接、标题、标签、备注、星标、归档状态与当前下载结果。
- `attempts/`：各次下载记录和暂存文件。
- `media/`：经过校验的本地视频副本，带 SHA-256 完整性记录。

设置 `DOUYINMIND_LOCAL_MEDIA_ROOT` 可更换本机工作目录。当前未实现自动清理，重试和暂存文件会占用磁盘；需要备份时停止后台，再备份整个目录。不要把存储内容、账号状态或密钥加入 Git 提交。

网络资料库保持单机使用，服务应绑定 `127.0.0.1`。局域网共享、多用户权限、自动同步收藏夹及知识库索引均不在本阶段范围。
