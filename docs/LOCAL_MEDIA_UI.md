# 本地媒体工作台使用说明

在浏览器中导入本机视频或音频，查看带时间的逐字稿、播放原片、保存人工笔记并导出。无需登录抖音。默认导入已有字幕；没有字幕时，需要另外配置并授权云端声音识别。**当前没有离线语音识别，真实 Qwen 云端识别尚未完成验收。**

## 打开工作台

先按 [README 的快速开始](../README.md#快速开始) 准备 Python、后端依赖、Node.js 和前端依赖。项目仍需本地运行环境，不是免安装的桌面软件。

ffmpeg 必须能被启动程序找到。若希望以后双击也能使用，在 Windows 的“编辑账户的环境变量”中，把包含 `ffmpeg.exe` 的 `bin` 文件夹添加到用户 `Path`，保存后重新打开启动窗口。仅在某次 PowerShell 中临时设置 `$env:PATH`，不会自动作用于以后双击启动的窗口。也可把已经准备好的 `ffmpeg.exe` 放在 `backend/app/storage/tools/ffmpeg.exe`。

双击项目根目录的 **`启动项目.bat`**，保持启动窗口打开，然后访问 [本地媒体工作台](http://127.0.0.1:5173/#local)。也可在首页点击“导入本地视频 / 音频”，或在原工作区点击“本地资料”。左侧显示“本机处理已就绪”后即可操作。

## 导入一份媒体

1. 点击“选择视频或音频”。目前支持 **MP4、MP3、M4A、WAV**，每个文件不超过 **500 MiB、30 分钟**，且必须有可解码音轨；一次处理一份媒体。
2. 有字幕时保留默认“导入已有字幕”，再选择对应的 **SRT/VTT** 文件，大小不超过 **10 MiB**。点击“导入字幕与媒体”，全程不调用云端模型。字幕的内容和覆盖范围仍需你核对。
3. 查看“最近处理”中的阶段、分段进度和错误提示。页面刷新后仍可查看任务；离开网页不会主动停止后台任务。
4. 完成后，在“我的本地资料”选择文件。点击逐字稿时间可跳到原片对应位置，也可搜索当前逐字稿。浏览器不支持某种视频编码时，尝试 H.264 视频与 AAC 音频编码的 MP4；已有文字仍可查看和导出。

浏览器先把所选文件传给**同一台电脑上的后台**，后台保存受管理的媒体副本。它不是原文件路径，网页不会写回你选择的原件；这是本机保存，与下一节的云端音频上传不同。

## 没有字幕时使用云端识别

在本机 `backend/.env` 配置服务，不要把真实密钥放进网页、源码或 Git 提交。需要的变量是：

| 变量 | 用途 |
| --- | --- |
| `QWEN_OMNI_API_KEY` | Qwen 服务密钥；未设置时使用 `DASHSCOPE_API_KEY` |
| `DASHSCOPE_API_KEY` | 可选的密钥来源 |
| `QWEN_OMNI_MODEL` | 账号可用的模型名称 |
| `QWEN_OMNI_BASE_URL` | 与账号和密钥服务区域一致的地址 |

修改配置后，停止并重新启动后台，再在网页点击“重新连接”。只刷新页面不会重新加载后台配置；“已配置”也不等于服务商已验证密钥或模型可用。

选择“识别视频中的声音”，核对显示的模型与服务地址，设置本次最多请求次数，单独勾选本次音频上传与费用授权，再点击“开始声音识别”。只有获得该次授权后才会向配置的 Qwen 服务发送提取的音频片段；原视频副本留在本机。

请求次数范围为 **1–100**，默认 **8**，包括分段与重试。**请求次数不是金额上限**；达到次数上限会停止后续请求并保留已完成分段。实际费用应在服务商控制台核对。本阶段真实云端识别尚未验收，请先使用你有权处理的一小段素材核对内容、时间和用量。

## 笔记与导出

“人工笔记”是独立文件，修改后点击“保存笔记”。重新导入或识别不会覆盖它。若其他窗口已保存了更新，当前草稿会保留，并显示最新内容供比较；先在编辑框中合并，再点击“已核对，用当前草稿保存”。该操作会以合并后的草稿替换最新笔记。离开页面前保存，导出只包含已保存内容。

展开“导出文件”可下载五种文件：

| 文件 | 内容 |
| --- | --- |
| `source_manifest.json` | 来源、散列、处理配置和阶段状态 |
| `transcript.json` | 片段 ID、整数毫秒时间和文字 |
| `transcript.md` | 带时间的完整逐字稿 |
| `knowledge.md` | 知识笔记结构与“未生成 AI 总结”状态 |
| `notes.md` | 最近一次保存的人工笔记 |

尚未完成处理时，部分文件还不可下载。**本地工作台关闭 AI 总结，也未接入知识库检索或跨视频问答。** 字幕导入和模型输出均需人工校对，不能把已有字幕当作本次 ASR 结果。

## 失败、取消与重启

| 看到的情况 | 接下来怎么做 |
| --- | --- |
| 无法连接本机服务 | 检查启动窗口是否仍在运行；重新启动后，点击网页“重新连接”。 |
| 没有找到 ffmpeg | 检查安装位置及 `Path`，重新启动后台，再点击“重新连接”。 |
| 文件或字幕无效 | 检查格式、大小、音轨，以及字幕时间是否落在这段媒体内；改好后重新选择文件。 |
| 云端尚未配置或调用失败 | 检查本机服务配置、账号模型和区域；修改配置需重启后台，再手动重试。 |
| 请求次数已用完 | 核对已完成分段与服务用量；确需继续时，点击“重试”，重新设置次数并授权。 |
| 任务正在处理但想停止 | 点击“停止后续处理”。已发出的请求可能仍会完成并计费，已有结果和可恢复分段会保留。 |
| 后台重启后显示“已中断” | 点击“重新连接”更新网页连接，再手动“重试”。重启不会自动重新发送云端请求；云任务重试需再次授权。 |
| 新一次处理失败但还能看到文字 | 当前展示的是此前保存的成功结果，并不表示最新一次处理成功。 |

## 文件保存在什么地方

默认目录为 **`backend/app/storage/local_media_workspace/`**，保存受管理媒体、任务记录、人工笔记、结果和处理缓存。工作台不会自动读取或迁移 Phase 1 CLI 的 `backend/app/storage/local_imports/`；要在网页查看，请重新选择媒体与字幕导入。

当前没有自动清理机制，上传暂存文件、媒体副本、缓存和结果会占用磁盘。不要在任务运行中手工移动或删除存储目录；需要备份时，先停止后台再备份整个目录。资料属于本机私人数据，不应提交 GitHub。

实际验证范围与剩余限制见 [Phase 2 报告](PHASE2_REPORT.md)；命令行入口仍见 [Phase 1 CLI 说明](LOCAL_MEDIA_IMPORT.md)。
