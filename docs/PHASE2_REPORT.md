## 交付结论

本地浏览器工作台已实现并完成真实浏览器离线验收。用户无需登录抖音，可以选择本地视频或音频、导入已有字幕、查看任务和逐字稿、点击时间回看媒体、编辑独立笔记并下载五份产物。

**Phase 2A（本地工作台）通过本轮验收；Phase 2B（真实云端识别与质量验收）尚未完成。** 本轮没有发送真实云请求，也没有用已有字幕或测试替身冒充 ASR 成功。云端入口及调用控制已接入，但不能据此宣称真实模型可用、中文识别质量可靠、长视频已验收或已达到普通用户安装即用的产品状态。

使用步骤见 [本地工作台使用说明](LOCAL_MEDIA_UI.md)。Phase 1 CLI 保留，旧结果不会自动迁入网页资料列表。

## 用户可操作的范围

- 首页和原工作区提供本地资料入口；`/#local` 可直接打开，刷新保持入口。
- 单文件 MP4 / MP3 / M4A / WAV；媒体上限 500 MiB、时长上限 30 分钟；SRT/VTT 上限 10 MiB。30 分钟是限制值，不代表已做同长度的真实云端识别验收。
- 默认导入已有字幕。云端识别另选模式并逐次确认授权；页面显示服务配置、模型和真实云验收状态。网页本轮不启用 AI 总结。
- 展示持久任务状态、处理阶段、分段进度及云请求数；支持停止后续处理和手动重试。
- 原视频/音频播放、毫秒时间跳转、当前逐字稿搜索、来源标记及未人工校对提示。
- 人工笔记独立保存；多页面或外部编辑冲突时保留草稿，要求核对后再保存。
- 导出 `source_manifest.json`、`transcript.json`、`transcript.md`、`knowledge.md`、`notes.md`。知识笔记明确保留未生成 AI 总结状态。

## 实现边界与恢复行为

后端新增 `local_media_workspace` 服务和 `/api/local-media` 路由，前端新增独立客户端和工作台；复用既有 worker、ffmpeg、导入编排、Omni 返回契约和 checkpoint。没有新建数据库或向量索引，也没有把本地资料加入原知识库搜索/RAG。

上传只发往本机服务，并使用服务器生成的文件名。原媒体以 SHA-256 标识保存受管理副本；同内容再次上传去重。任务 JSON、可变处理缓存、独立成功结果快照和人工笔记分别保存。只有全部产物复制和校验成功后才发布新的结果指针。失败、取消或请求预算用尽不会替换之前成功的结果。

运行一次仅允许一个活动的本地媒体任务。服务重启把未结束任务标为 `interrupted`，不会自动重试或重新发送云请求。取消停止后续请求；已发送请求仍可能完成并产生费用。新运行控制使用普通异常退出，验证了取消首任务后同一个 worker 还能完成第二个任务。

受控云调用关闭 SDK 内部重试；显式分段及恢复重试共用请求预算，范围 1–100 次。请求记录仅保留供应商、模型、服务地址、状态、请求标识及数值 usage 白名单，不写入凭证或供应商响应正文。**请求次数上限不是金额上限，也不能撤销已经发送的请求。** ProviderConfig 显式传入，空配置不会回退读取其他环境凭证。现有网页启动仍按原有方式读取服务端配置；这与 Phase 1 CLI 默认不读取 `.env` 的行为不同。

本地路由检查 Host/Origin，写请求需要进程内随机会话令牌；前端令牌只在内存保存。浏览器播放及下载无需自定义写请求头，但仍受本地来源检查。服务器使用文件白名单及受管理路径检查，不接受任意用户文件路径。此设计面向单机单后端进程，不是多用户权限体系。

独立复审发现并修复了两项具体问题：

1. 取消与完成回调可能乱序，旧快照把已完成请求退回 `in_flight`。新增单调 revision 并拒绝过时回调；用真实两线程稳定复现了旧实现失败并验证修复。
2. 受管理媒体损坏后，正确重传可能被当作重复文件删除。现在删除冗余上传前校验已有媒体；必要时用已验证重传经过临时文件、fsync、散列检查和原子替换修复。修复失败保留正确上传及已有笔记/结果；独立真实离线探针和三项新回归通过。

最终发布之前取消的竞态也有回归保护。中途一次旧测试因运行时长参数默认值与 monkeypatch 上限不一致失败，已修复为同时遵守有效上限；没有修改原断言，最终全量通过。API 测试首次网络隔离误拦 Windows asyncio 的 loopback socketpair，已仅允许本地 selfpipe，继续阻止外部连接。

## 后续范围

下一步只做受控真实 ASR 验收，暂不扩展批量同步、跨视频问答、桌面安装器或更多供应商：

1. 确认服务端可用凭证、准确模型标识和端点，凭证由用户在本机设置，不贴入聊天或写进提交。
2. 先用已许可的 120 秒 Sintel 验证“浏览器选媒体、不提供字幕、授权、真实 Qwen 音频识别、结果回看和导出”。在调用前确定本次请求上限及可接受费用；次数上限不能代替供应商侧金额限制。
3. 记录真实请求标识、usage、耗时、模型和配置、实际产物、费用可核验情况以及未人工校对声明。供应商不返回 usage 时保留缺失，不补造数字。
4. 再用获准的短中文清晰语音样本和噪声/静音样本做人工核对，记录漏句、专名错误、时间偏移和是否误报无语音。Sintel 英文连接成功不能证明中文质量。
5. 验证真实请求后的失败恢复和缓存复用后，再决定是否增加长度或默认开放云端入口。

尚未完成的产品工作包括首次安装体验、受支持浏览器/编码矩阵、资料删除与磁盘总配额、多进程协调、真实识别质量门槛。当前没有自动清理策略，重复任务会保留成功快照；应预留磁盘空间。原抖音收藏夹两项缺陷仍需在恢复批量同步前修复。
